Derives a lower bound on the optimal cost of any causal output-feedback controller by applying the Gibbs variational principle to the closed-loop state/observation path measure against a reference measure in which observations are decoupled from state, giving J_irr(Ī) = sup_β{inf_u F^x_β(u) + J^u_trj(u) − Ī/β} ≤ J* for any MI budget Ī. Its key move is a cost-information certificate Ī(J) (a policy with cost ≤ J has bounded state second moments and so bounded sensor MI) closed into a fixed point J_sc = J_irr(Ī(J_sc)) that is unique, found by bisection, and strictly tighter than the TRIP-style bound that evaluates MI under the open-loop distribution; on a scalar LQG it captures over 80% of J* at σ_v ≈ 10, and on Dubins tracking it stays informative where the open-loop-MI bound is vacuous. Relevant as a formal instance of a performance limit whose channel information is set by the closed-loop distribution (control concentrates the state, which starves the fixed sensor of information), though the sensor map itself is fixed and not policy-dependent.
